# Bit Manipulation Cheat Sheet

## Basic Operations

| Purpose | Trick |
|-----------|--------|
| Check if number is odd | `n & 1` |
| Check if number is even | `(n & 1) == 0` |
| Multiply by 2 | `n << 1` |
| Divide by 2 | `n >> 1` |
| Get kth bit | `(n >> k) & 1` |
| Check kth bit | `n & (1 << k)` |
| Set kth bit | `n \| (1 << k)` |
| Unset kth bit | `n & ~(1 << k)` |
| Toggle kth bit | `n ^ (1 << k)` |
| Flip all bits | `~n` |
| Get negative number | `~n + 1` or `-n` |

---

## Rightmost Bit Tricks

| Purpose | Trick |
|----------|--------|
| Remove rightmost set bit | `n & (n - 1)` |
| Get rightmost set bit | `n & (-n)` |
| Set rightmost unset bit | `n \| (n + 1)` |
| Get rightmost unset bit | `~n & (n + 1)` |

---

## Power of 2 Tricks

| Purpose | Trick |
|----------|--------|
| Check power of 2 | `(n > 0) && ((n & (n - 1)) == 0)` |
| Lowest power of 2 factor | `n & (-n)` |
| Power of 2 using popcount | `__builtin_popcount(n) == 1` |

---

## Set Bit Counting

| Purpose | Trick |
|----------|--------|
| Count set bits | `__builtin_popcount(n)` |
| Count set bits (long long) | `__builtin_popcountll(n)` |
| Count set bits manually | Repeatedly `n & 1` |
| Count set bits efficiently | Repeatedly `n &= (n - 1)` |

---

## XOR Tricks

| Purpose | Trick |
|----------|--------|
| Same numbers XOR | `a ^ a = 0` |
| XOR with 0 | `a ^ 0 = a` |
| Find single element (others twice) | XOR all elements |
| Find missing number | XOR expected and actual |
| Swap without temp | `a ^= b; b ^= a; a ^= b;` |

---

## Bitmask / Subset Tricks

| Purpose | Trick |
|----------|--------|
| Total subsets | `1 << n` |
| Check if ith element selected | `mask & (1 << i)` |
| Add ith element | `mask \| (1 << i)` |
| Remove ith element | `mask & ~(1 << i)` |
| Toggle ith element | `mask ^ (1 << i)` |

### Iterate Through All Subsets

```cpp
for(int mask = 0; mask < (1 << n); mask++) {
    // process subset
}
```

## Useful Identities

| Identity | Result |
|-----------|---------|
| `n & 0` | `0` |
| `n \| 0` | `n` |
| `n ^ 0` | `n` |
| `n ^ n` | `0` |
| `n & n` | `n` |
| `n \| n` | `n` |
| `~~n` | `n` |

---

## Most Important Patterns

| Expression | Meaning |
|------------|----------|
| `n & (n - 1)` | Remove lowest set bit |
| `n & (-n)` | Isolate lowest set bit |
| `n \| (n + 1)` | Set lowest unset bit |
| `~n & (n + 1)` | Isolate lowest unset bit |
| `(n & (n - 1)) == 0` | Check power of 2 |
| `__builtin_popcount(n) == 1` | Check power of 2 |
| `n ^ (1 << k)` | Toggle kth bit |
| `n & ~(1 << k)` | Clear kth bit |
| `n \| (1 << k)` | Set kth bit |

---

## Interview Must-Know

```cpp
n & 1                 // odd/even

n & (n - 1)           // remove lowest set bit

n & (-n)              // isolate lowest set bit

(n & (n - 1)) == 0    // power of 2

__builtin_popcount(n) // count set bits
```
